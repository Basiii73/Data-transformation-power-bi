# Data Transformation and Visualization with Power BI

This project involves cleaning and visualizing the sales data of GLOBAL SUPERSTORE using Microsoft Power BI.

## Project Overview

The objective of this project is to transform raw sales data into meaningful insights through data cleaning and visualization techniques in Power BI.

## Files in the Repository

- **GLOBAL SUPER STORE.pbix**: Power BI file containing the data cleaning and transformation processes.
- **Data visualization.pbix**: Power BI file showcasing various visualizations of the cleaned sales data.
- **Data visualization.pdf**: PDF document presenting the visualizations for easy viewing without Power BI.

## Data Cleaning and Transformation

The data cleaning process includes:

- **Removing Duplicates**: Ensuring each record is unique to maintain data integrity.
- **Handling Missing Values**: Addressing any gaps in the data to ensure completeness.
- **Correcting Data Types**: Ensuring all data fields have appropriate data types for accurate analysis.
- **Standardizing Formats**: Uniform formatting of dates, currencies, and other fields for consistency.

These steps were performed using Power BI's Power Query Editor.

## Data Visualization

The visualizations provide insights into:

- **Sales Performance**: Analysis of sales trends over time.
- **Profit Margins**: Evaluation of profitability across different products and regions.
- **Geographical Analysis**: Sales distribution across various locations.
- **Product Categories**: Performance of different product categories and sub-categories.

These visualizations were created using Power BI's visualization tools, including bar charts, line charts, and maps.

## Getting Started

To explore the project:

1. **Download Power BI Desktop**: Ensure you have Power BI Desktop installed on your machine.
2. **Clone the Repository**: Download or clone this repository to your local machine.
3. **Open `.pbix` Files**: Use Power BI Desktop to open the `.pbix` files and explore the data cleaning steps and visualizations.
